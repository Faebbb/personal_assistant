# Персональний помічник (CLI)

Навчальний командний проєкт курсу **Python Programming: Foundations and Best Practices**.
Застосунок працює в командному рядку та дозволяє керувати контактами й нотатками. Дані автоматично зберігаються на диску, тому не втрачаються після перезапуску програми.

## Можливості

### Контакти

- додавання, редагування та видалення контактів;
- збереження імені, кількох телефонів, email, адреси та дня народження;
- валідація імені, телефону, email, адреси та дня народження;
- нормалізація українських номерів телефону до формату `+380XXXXXXXXX`;
- пошук за іменем, телефоном, email або адресою;
- виведення контактів, у яких день народження протягом заданої кількості днів.

### Нотатки

- додавання, редагування та видалення нотаток;
- текстові нотатки з тегами;
- пошук за назвою, текстом або тегом;
- точний пошук за тегом;
- сортування нотаток за тегами;
- сортування всіх нотаток за датою створення.

### Збереження даних

Дані зберігаються у домашній папці користувача:

```text
~/.personal_assistant/contacts.json
~/.personal_assistant/notes.json
```

Збереження виконується автоматично після команд, які змінюють або переглядають стан програми, а також під час виходу.

## Використані принципи ООП

Проєкт демонструє:

- **спадкування**: `Field` → `Name`, `Phone`, `Email`, `Birthday`, `Address`, `Tag`;
- **композицію**: `Record` містить об'єкти полів контакту, `Note` містить об'єкти `Tag`;
- **інкапсуляцію та валідацію** через властивості та методи моделей;
- окремі класи-контейнери `AddressBook` та `NotesBook`.

## Вимоги

- Python 3.9 або новіший;
- додаткові сторонні бібліотеки не потрібні.

## Встановлення

### 1. Клонування репозиторію

```bash
git clone https://github.com/Faebbb/personal_assistant.git
cd personal_assistant
```

### 2. Встановлення як Python-пакета

Рекомендовано створити віртуальне середовище:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Windows CMD:

```cmd
.venv\Scripts\activate.bat
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Після активації:

```bash
python -m pip install --upgrade pip
pip install -e .
```

Тепер застосунок можна запускати з будь-якої папки командою:

```bash
personal-assistant
```

Також можливий запуск без встановлення:

```bash
python -m personal_assistant.main
```

## Команди

| Команда | Опис |
|---|---|
| `help` або `?` | показати довідку |
| `add-contact` | додати новий контакт |
| `edit-contact` | редагувати контакт |
| `delete-contact` | видалити контакт |
| `search-contact` | знайти контакти |
| `all-contacts` | показати всі контакти |
| `birthdays` | дні народження протягом 7 днів |
| `birthdays N` | дні народження протягом N днів |
| `add-note` | додати нотатку |
| `edit-note` | редагувати нотатку |
| `delete-note` | видалити нотатку |
| `search-note` | пошук за назвою, текстом або тегом |
| `search-tag tag` | пошук за точним тегом |
| `all-notes` | показати всі нотатки |
| `sort-notes-tag` | відсортувати нотатки за тегами |
| `exit`, `quit`, `close`, `q` | зберегти дані та вийти |

## Редагування та очищення полів

Під час редагування `Enter` залишає значення без змін.
Для очищення необов'язкового поля введіть `-`.

Наприклад, так можна видалити email, адресу, день народження, текст нотатки або всі теги.

## Обробка помилок

Програма не завершується через некоректні користувацькі дані. Вона повідомляє про помилку та дозволяє продовжити роботу. Перевіряються, зокрема:

- порожні імена та назви нотаток;
- формат номера телефону;
- формат email;
- коректність і майбутня дата народження;
- дублікати контактів, нотаток і номерів телефонів;
- некоректне число днів у команді `birthdays`;
- пошкоджені або некоректні записи у файлах даних.
